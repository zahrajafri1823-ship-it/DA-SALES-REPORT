# DA-SALES-REPORT - AMAZON SALES REPORT

## Overview
This project focuses on analyzing an Amazon India sales dataset to understand sales performance, product demand, regional trends, and order status distribution using descriptive analytics.

## Objectives
- Identify the top 10 best-selling products.
- Analyze state-wise and city-wise sales.
- Study order status distribution.
- Compare category-wise sales and quantity.
- Analyze product size demand.
- Summarize key business insights using visualizations.

## Tools & Technologies
- Python
- Pandas – Data analysis and manipulation
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Jupyter Notebook – Data analysis environment

## Key Findings
- Top-selling product: JNE3405 (Kurta)
- Top-performing state: Maharashtra
- Top-performing city: Mumbai
- Highest revenue category: Kurta
- Most common order status: Shipped
- Highest-demand size: 3XL

## Conclusion
This project demonstrates how descriptive analytics helps identify sales patterns, understand customer demand, and support data-driven business decisions. It also explores how the analysis could be extended to predictive analytics in the future.


# IBM COGNOS ANALYTICS PRACTICALS

## About the Project
This repository contains practical assignments completed using **IBM Cognos Analytics**. These practicals demonstrate report creation, data grouping, filtering, crosstab analysis, and dashboard visualization using different datasets.

## Practicals Included

### Practical 1: Create a List Report
Create a list report using the sales dataset. The report presents data in a structured tabular format, making it easier to read and analyze sales information.

### Practical 2: Group Data and Add Summary
Create a report that organizes sales data using meaningful groups and adds a summary footer. This helps present information clearly and understand overall sales values.

### Practical 3: Filter Sales Data by Region
Create a report that filters RetailPulse Sales data based on the selected region. This allows users to focus on sales information for a particular geographical area.

### Practical 4: Build a Region-Product Crosstab
Create a crosstab report to compare sales across different regions and product categories. This makes it easier to identify sales patterns and compare product performance between regions.

### Practical 6: Build a Customer Insights Dashboard
Create a dashboard using a separate customer dataset. The dashboard combines visualizations and customer-related information to make data easier to understand and support customer insights.

## Datasets Used
* **Sales Dataset:** Used for Practicals 1, 2, 3, and 4.
* **Customer Dataset:** Used separately for Practical 6 to create the Customer Insights Dashboard.

## Tools Used
* IBM Cognos Analytics
* CSV datasets

## Objective
To gain practical experience in data reporting, grouping, filtering, summarization, crosstab analysis, and dashboard creation using IBM Cognos Analytics.
